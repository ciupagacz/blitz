### About the project

**Blitz is a small library made for the C language, which provides several QoL definitions and functions**.
It makes stuff like declaring variables, using default functions, managing memory, strings and random numbers much easier and faster. <br>
It was mostly made for personal use, but I'll try to implement as much stuff to it as possible in the nearby future. <br>
Blitz doesn't have stable and unstable branches; instead it uses push system, so that the every change made to the code is applied automatically.
Don't worry though, I'm not planning to modify syntax in a nerby future. <br>
You can learn more about blitz on the wiki page, which'll be available soon enough.
